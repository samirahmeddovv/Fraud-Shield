# Fraud Shield 💳🛡️

**Fraud Shield** is an automated web application designed to detect and prevent fraudulent financial transactions. Built as a university coursework project, it combines a Python/Flask backend with an Oracle Database to analyze transaction patterns and flag high-risk activities in real time.

## 🚀 Key Features
* **Transaction Monitoring:** Tracks and inspects incoming financial transactions against predefined security rules.
* **Fraud Detection Engine:** Flags suspicious activities and potential fraudulent behavior automatically.
* **Database Integration:** Securely logs transactions, user data, and flagged alerts using Oracle Database.
* **Web Dashboard:** A clean interface built with Flask to view transaction histories and system statuses.

## 🛠️ Built With
* **Backend:** Python, Flask
* **Database:** Oracle Database (Oracle SQL Developer)
* **Logic:** Rule-based fraud detection algorithms
